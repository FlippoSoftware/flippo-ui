---
title: Installation
description: Which packages to install, and how to add them to an application.
---

Every package is published on its own under `@flippo-software/*`; install the one of your layer, its dependencies
come with it. All packages are ESM with a CommonJS build and their own TypeScript declarations.

## Styled React components

```sh
pnpm add @flippo-software/ui-kit-react @flippo-software/component-styles react react-dom
```

`component-styles` and React 19 are peer dependencies: the application has one copy of each. Import the stylesheet once
at the entry point and wrap the application in `FlippoProvider` (theme, size of the controls):

```tsx
import '@flippo-software/ui-kit-react/styles.css';
import { Button, FlippoProvider } from '@flippo-software/ui-kit-react';

export function App() {
    return (
        <FlippoProvider storageKey="flippo-theme">
            <Button>Create a set</Button>
        </FlippoProvider>
    );
}
```

## Styled custom elements

```sh
pnpm add @flippo-software/ui-kit-web @flippo-software/component-styles
```

Register the elements once with a prefix of your own: it starts every tag name.

```ts
import '@flippo-software/ui-kit-web/styles.css';
import { define } from '@flippo-software/ui-kit-web';

define({ prefix: 'ui' }); // <ui-button>, <ui-dialog>, <ui-dialog-trigger>…
```

## Unstyled components

```sh
pnpm add @flippo-software/react-components react react-dom   # React
pnpm add @flippo-software/web-components                     # custom elements
```

They render no styles: style their parts with your CSS, using the `data-*` attributes of their states. Import a
component from its entry point to load only what you use:

```tsx
import { Dialog } from '@flippo-software/react-components/dialog';
```

```ts
import { define } from '@flippo-software/web-components/dialog';

define({ prefix: 'ui' });
```

## Only the styles

```sh
pnpm add @flippo-software/component-styles
```

The tokens, the themes and the CSS of the components, for your own markup: the class recipes return the classes of
each part (`button({ variant: 'secondary' })`), the SCSS API gives the tokens and mixins.

## Requirements

- Browsers with the Popover API, `light-dark()` and CSS cascade layers (the current Chrome, Edge, Firefox and Safari).
- React 19 for the React packages.
- Server rendering: the packages import without a DOM; the React components render on the server.
